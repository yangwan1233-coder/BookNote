🎉 BookNote v1.0.0 正式版首发
欢迎使用 BookNote！这是一款基于 Android 16 与 Jetpack Compose 打造的极简、现代且硬核的备忘录应用。我们致力于将“灵感记录”与“极客级数据安全”完美融合，为你带来丝滑的原生记录体验。

🎨 视觉与交互体验 (UI/UX)

沉浸式全面屏：全面适配 Android 16 的边缘到边缘 (Edge-to-edge) 显示，让你的文字和图片在状态栏底下自由穿梭，阅读视野不受限 。


莫奈动态色彩 (Material You)：应用主题色会根据你的手机系统壁纸颜色自动提取与变幻，千人千面，完美融入系统 。


灵动的气泡导航：彻底重构底部导航栏，采用居中悬浮胶囊设计；点击图标时，气泡背景会带有物理弹簧效果丝滑滑动 。


悬停滑动菜单：主页笔记不仅按年份自动生成精美气泡分组，还支持手写物理回弹算法的“左滑悬停”手势，轻松呼出【存档】与【删除】快捷操作 。

📝 强大的富文本编辑

“时光倒流”双向历史栈：内置底层历史状态列队，支持文字输入的【撤销上一步】与【重做下一步】，打错字随时一键反悔 。


精准智能列表：长按滑动选中任意段落，点击快捷排序按钮即可无缝追加“•”黑点列表符号，绝不误伤未选中的上下文 。


沉浸式图文混排：支持插入多达 9 张图片，自动排版为完美正方形九宫格 。底层采用 Coil 引擎，完美兼容 RAW、WebP、PNG 等全格式图像 。


全屏画廊与快捷工具：点击图片即可进入带有黑色毛玻璃遮罩的全屏沉浸式查看器，长按图片快速删除 。键盘上方配备悬浮栏，支持一键光标插入 () 以及动态 H 标题联动正文缩放 。


智能防呆：离开编辑页实时自动保存；如果你只新建了笔记但没写任何字、没发任何图，系统会自动将其判定为“空白垃圾”并无痕舍弃 。

🗂️ 极客级数据与存储管理

真正的 0 App 存储占用：打破沙盒限制！全面接入系统级 SAF 存储框架。你的所有文字数据和超清原图都会直接保存在你自定义的公共文件夹中，即便卸载应用，你的心血笔记也绝不丢失 。


深度 ZIP 备份引擎：这不是普通的文本导出！一键点击备份，系统会在后台将全部文本与关联的图片完整打包为 .zip 压缩包。换机时只需一键恢复，图片与文字原样重生，实现跨设备完美克隆 。


多格式导入器：内置文件解析引擎，完美支持从外部直接导入 .txt 与 .md (Markdown) 格式的文稿 。


安全防误删：配备独立的【归档箱】与【回收站】，支持批量点选恢复，或者一键彻底清空 。

🚀 新手友好与性能优化

首次安装向导：首次打开应用时，主页会静默且极速地自动注入一条图文并茂的“极速上手指南”。带你了解所有隐藏的高阶功能，阅读完毕后一键左滑即可彻底销毁，绝不反复打扰 。


底层 IO 协程优化：所有的文件保存与读取均通过 Kotlin Coroutines (协程) 分发至底层后台线程处理，彻底告别打字卡顿与掉帧 。


极致瘦身：全面开启 R8 代码混淆与无用资源剔除，安装包体积迎来断崖式缩减，轻盈且省电 。
